## 🎯 Quick Start

### For End Users
```bash
# Create a new Next.js app with billing
npx create-nozle-app my-app
cd my-app
npm run dev
```
See [create-nozle-app documentation](./create-nozle-app.md)

```bash
# Install SDKs
npm install @nozle-js/react @nozle-js/node
```

## 🔗 Cross-References

### How Components Connect

1. **User creates app** → `create-nozle-app` generates Next.js with SDKs
2. **App uses SDKs** → `@nozle-js/react` and `@nozle-js/node` make API calls
3. **SDKs call Engine** → Go API handles requests
4. **Engine uses Lago** → Billing operations via Lago API
5. **Real-time updates** → Centrifugo pushes to client via WebSocket

### Key Integration Points

| From | To | Purpose | Doc Link |
|------|----|---------|----|
| create-nozle-app | @nozle-js/* | Generates app with SDKs | [CLI](./create-nozle-app.md#generated-app) |
