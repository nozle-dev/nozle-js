# create-nozle-app

Create a production-ready Next.js SaaS app with Nozle billing integration.

**Templates are always fresh** - fetched directly from the [templates](https://github.com/nozle-dev/templates) repository.

## Quick Start

```bash
npx create-nozle-app my-app
```

## Templates

Choose from 4 production-ready templates:

1. **Flat Subscription** - SaaS workspace (Notion/Linear style)
2. **SaaS + Usage** - API platform with overage (Stripe/Twilio style)
3. **Compute** - Infrastructure dashboard (Vercel/Railway style)
4. **Credit-Based** - Prepaid marketplace (Midjourney/Canva style)

Each template includes:
- ✅ Complete page implementations
- ✅ Dashboard with all features
- ✅ Billing integration (pricing, checkout, portal)
- ✅ API routes
- ✅ Database schema (demo + production modes)
- ✅ Full TypeScript + Tailwind + shadcn/ui
